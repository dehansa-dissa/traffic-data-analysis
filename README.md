# 🚦 Traffic Data Analysis

A data analysis project focused on extracting insights from traffic datasets using Python.  
This project explores traffic patterns and visualizations to better understand road usage and mobility behavior.

---

## 📌 Overview

This project analyzes traffic data to:

- Understand traffic flow patterns
- Identify peak hours and congestion trends
- Visualize traffic distribution

---

## 🛠️ Tech Stack

- Python 🐍
- Tkinter
